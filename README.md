# S.EUS

S.EUS is a modular browser-based code execution platform.

## Features

- HTML Playground
- CSS Playground
- JavaScript Playground
- Live Preview
- Automatic Execution
- Console
- Local Storage
- Responsive UI

## Development

Install dependencies:

    npm install

Run development server:

    npm run dev

Build:

    npm run build

Preview production build:

    npm run preview

## Routes

- /
- /html
- /css
- /js

## Tech Stack

- HTML
- CSS
- JavaScript
